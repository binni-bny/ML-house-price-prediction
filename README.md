# California House Price Predictor

A machine learning project that predicts house prices using the California Housing dataset (20,640 neighborhoods).

## Results
- Linear Regression: R2 = 0.58, average error = $53,000
- Random Forest: R2 = 0.80, average error = $33,000

## How to run
'''
pip install -r requirements.txt
python train_forest.py
'''
